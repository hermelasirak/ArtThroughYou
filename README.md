# Art Through You

An interactive journey through five eras of art, where six personal choices shape a unique character and transform that character into a portrait inspired by art history.

Visitors travel through five eras of art history, making one decision in each, then reflect on what they want people to feel when they see their portrait. Those choices build a character profile, match it to one of five art eras, and shape a one-of-a-kind portrait painted in that era's style.

## Run locally

Requirements: Node.js 20+ and npm.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open http://localhost:3000. The app works in **Demo Mode** without API keys. Progress is stored in the browser's local storage.

## AI setup

The app uses Cloudflare Workers AI for the portrait image. All results text (identity, core quality, how the choices shaped the portrait) is built from the choice mapping in `src/lib/quiz.ts`, not generated by AI.

Add these server-side keys to `.env.local`:

```env
CLOUDFLARE_ACCOUNT_ID=your_cloudflare_account_id
CLOUDFLARE_API_TOKEN=your_workers_ai_api_token
```

- **Cloudflare Workers AI FLUX.1 schnell** generates the personal portrait. The Workers AI Free plan includes 10,000 Neurons per day; usage beyond the free allocation requires a paid Workers plan.
- `src/lib/gemini.ts` is a Gemini text helper that nothing currently calls. `GEMINI_API_KEY` is only needed if a feature starts using it again.

To create Cloudflare credentials, open **AI > Workers AI > Use REST API** in the Cloudflare dashboard, select **Create a Workers AI API Token**, and copy the Account ID. If creating a token manually, grant **Workers AI - Read** and **Workers AI - Edit** permissions. Add both values to Vercel under Project Settings > Environment Variables (Production, Preview and Development), then redeploy.

Never put secret keys in `NEXT_PUBLIC_` variables or commit `.env.local`.

## Persistence

The initial MVP persists the complete journey in browser local storage, which makes the demo easy to run without infrastructure. The Supabase migration in `supabase/migrations/001_initial.sql` defines the remote schema for the next integration step. Before enabling remote persistence, add per-journey ownership, appropriate Row Level Security policies and server-side writes. The service-role key must remain server-only.

## Deploy to Vercel

1. Push this repository to GitHub.
2. In Vercel, select **Add New → Project** and import `Chimpfreak/ArtThroughYou`.
3. Keep the framework preset as Next.js and the root directory as `.`.
4. Add `CLOUDFLARE_ACCOUNT_ID` and `CLOUDFLARE_API_TOKEN` as environment variables.
5. Deploy. Demo Mode works without these keys.

A GitHub push does not itself publish a Next.js app. Vercel must be connected and the deployment must complete successfully.

## Current MVP scope

- Five chapters, one per era, each with six choices in a varied order. Each chapter shapes one portrait detail: symbol, setting, expression, colour and light, composition.
- A final reflection set in the present: "When someone looks at your portrait, what would you want them to feel?" Six feelings; the answer does not change the era match, but sets the portrait's mood and layers onto its expression, lighting and composition.
- Character matching: every answer (all six) adds points to five qualities: Curiosity, Connection, Creativity, Reflection and Independence. Each quality is scored 0–100 as the share of all possible journeys that score lower on it. The era is the archetype whose pattern across the five qualities correlates most closely with the visitor's profile, so no era is chosen just because an answer came from its chapter. Each era wins 16–23% of all possible journeys. Points and era patterns live in `src/lib/quiz.ts`.
- Individual answers separately shape the portrait's symbol, setting, expression, colour and light, composition and mood, so two people matched to the same era still get different portraits.
- The archetypes are creative framing, not scientific personality classifications.
- Results in three parts: artistic identity (archetype, character profile, matched era, core quality), the generated portrait with an explanation built from the answer-to-portrait mapping, and a five-card personal collection with an artwork for each chapter's choice, painted in the background during the journey.
- Cloudflare-generated portrait, with a clearly labelled preview when the image service is unavailable or demo mode is on.
- Optional photo: helps the portrait resemble the visitor (Stable Diffusion 1.5 img2img). The photo is centre-cropped and downsized in the browser, sent for that one request, and never stored.
- Printable results page.
- Local browser persistence and AI API endpoints.
